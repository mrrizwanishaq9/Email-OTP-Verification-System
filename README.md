Email OTP Verification System – Python & Google Colab

📌 Full Description

A professional Email OTP Verification System built with Python and Google Colab. This project provides a simple and secure way to verify an email using a randomly generated 6-digit OTP.

The user enters an email address, and the system generates an OTP with a 60-second expiration timer. The email is displayed in a masked format such as r*****n@gmail.com to improve privacy.

✨ Main Features
📧 Email input and validation
🔢 Random 6-digit OTP generation
⏱️ 60-second countdown timer
🔒 Masked email display
✅ Correct OTP verification
❌ Wrong OTP detection
⏰ Automatic OTP expiration
🔄 Resend OTP option
🎉 Successful verification message
🖥️ Interactive Google Colab interface
🛡️ Secure OTP generation using Python secrets
🚫 Invalid email detection
